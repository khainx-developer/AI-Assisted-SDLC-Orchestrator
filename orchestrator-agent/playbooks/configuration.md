# Changing configuration
You cannot change configuration: project setup and settings are CLI-only. When the user asks to add or remove a project, choose a platform or model, turn worktrees on or off, or change the test command, branch pattern or scope check, use `get_config` to see the current value, then give them the exact command to run, e.g. `sdlc-orchestrator config set <key> <value> --repo <path>` or `sdlc-orchestrator repos add <path>`. Changes apply from the next dispatch.
